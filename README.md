# Вкусные истории мира — клиент-серверная версия

Ветка client-server-v2 переводит проект из локального однопользовательского скрипта в многопользовательское веб-приложение.

## Архитектура

- **Веб-клиент:** регистрация, вход, настройки генерации, управление Telegram-направлениями и история публикаций.
- **API-сервер:** FastAPI, JWT-аутентификация, проверка владельца каждой записи.
- **База данных:** SQLAlchemy; SQLite для локального запуска, PostgreSQL рекомендуется для развёртывания.
- **Планировщик:** серверная фоновая задача проверяет расписания каждые 30 секунд. Сайт может быть закрыт.
- **Генерация:** системный промпт приложения + тема и промпт пользователя передаются GigaChat отдельными сообщениями.
- **Публикация:** Telegram Bot API. Поддерживаются личные сообщения и Telegram-каналы.
- **Изображения:** при включённой настройке используется Cloudflare Workers AI; при выключенной — только текст.

Данные настроек и публикаций привязаны к учётной записи. Один пользователь не может читать или менять каналы другого пользователя через API.

## Требования

Python 3.11+, токен Telegram-бота сервиса, ключ GigaChat. Для генерации изображений — Cloudflare Account ID и API Token. Для продакшена — HTTPS и PostgreSQL.

## Локальный запуск (Windows PowerShell)

~~~powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.server.example .env
~~~

Заполните .env:
- APP_SECRET_KEY — длинная случайная строка. Сгенерировать: python -c "import secrets; print(secrets.token_urlsafe(48))".
- GIGACHAT_CREDENTIALS — ключ GigaChat API.
- TELEGRAM_BOT_TOKEN — токен бота, созданного через @BotFather.
- Для изображений: CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_API_TOKEN, CLOUDFLARE_IMAGE_MODEL.

Запуск:

~~~powershell
uvicorn app.server:app --host 127.0.0.1 --port 8000
~~~

Откройте http://127.0.0.1:8000 и зарегистрируйте пользователя. Для разработки сервер доступен только на локальном компьютере.

## Настройка Telegram для пользователя

### Публикация в канал

1. Создайте Telegram-канал или откройте существующий.
2. Добавьте бота, токен которого настроен администратором сервиса, в администраторы канала.
3. Выдайте боту право **публиковать сообщения**.
4. В форме сайта выберите «Telegram-канал», укажите публичный адрес вида @my_channel или числовой ID приватного канала.
5. Сохраните канал, задайте расписание и включите автопостинг.

Пользователь сайта не вводит токен бота. Токен хранится только в переменных окружения сервера. В текущем MVP бот общий для сервиса, а назначения и настройки каналов принадлежат конкретным аккаунтам.

### Личные сообщения

1. Откройте бота сервиса в Telegram и нажмите **Start**. Бот не может первым написать пользователю.
2. Получите числовой Telegram chat ID. Для собственного бота это можно сделать через Telegram Bot API getUpdates после отправки боту сообщения. Не публикуйте ответ API, если в нём есть токен.
3. В веб-интерфейсе выберите «Личные сообщения» и укажите chat ID.
4. Сохраните расписание и включите автопостинг.

### Частота, тема и промпт

Общие настройки применяются ко всем каналам, если в карточке конкретного канала не задано переопределение темы или промпта. У каждого канала собственные интервал и часовой пояс. Генерация изображения включается отдельно для канала или общей настройки. Минимальный интервал — 15 минут.

## Социальные сети

В этой версии доступен только Telegram. Поле платформы в модели данных оставлено расширяемым для будущих интеграций. Дзен и его браузерная автоматизация в клиент-серверной версии не используются.

## Безопасность и ограничения текущего MVP

- Пароли хранятся как bcrypt-хеши; сессия API использует подписанный JWT.
- Установите сильный уникальный APP_SECRET_KEY, включите HTTPS за reverse proxy и используйте PostgreSQL для многопользовательского продакшена.
- Для нескольких процессов/реплик текущий встроенный планировщик запускать нельзя: он не использует распределённую блокировку. Пока запускайте один экземпляр API/worker.
- В MVP Telegram отправка и генерация выполняются в фоновой задаче процесса. Для высокой нагрузки вынесите worker в отдельный сервис и добавьте очередь задач и блокировки.
- Включение автопостинга приводит к реальной отправке сообщений по расписанию. Начните с личного тестового чата.
- Часовой пояс сохраняется в настройках, но текущая реализация интервала рассчитывает следующий запуск как длительность в минутах, а не календарное расписание по локальным часам.
- Изображение отправляется отдельным сообщением перед текстом. Если Cloudflare не вернул изображение, текстовая публикация всё равно отправляется.
- Токены и ключи не должны попадать в Git, логи или пользовательский интерфейс.

## Старый CLI

Старые модули генерации рецептов и публикации сохранены для миграции и обратной совместимости, но новая веб-версия запускается командой uvicorn app.server:app. Старый модуль Дзена не подключён к новому серверу.
