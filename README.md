# Вкусные истории мира — MVP

Ежедневная генерация рецепта на русском языке через Gemini API, сохранение в SQLite и публикация в Telegram-канал, откуда настроенный синхробот переносит материал в Дзен.

## Важные ограничения MVP

- Сначала запускайте с `DRY_RUN=true`: материал будет создан локально, но не отправлен в Telegram.
- Генерация изображений пока не реализована: бесплатный тариф для актуальных Gemini image-моделей не гарантирован. Это сделано намеренно, чтобы исключить неожиданные расходы.
- Валидатор проверяет базовую структуру, но не способен гарантировать фактическую безопасность или правильность каждого рецепта. Первые публикации следует проверять вручную.
- Для кросс-постинга настройте синхробота Дзена и укажите публичный Telegram-канал, связанный с вашим каналом Дзена.
- При `DRY_RUN=false` бот должен быть администратором Telegram-канала с правом публиковать сообщения.

## 1. Установка

Требуется Python 3.11 или новее.

### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
```

## 2. Получить ключ Gemini

1. Откройте https://aistudio.google.com/
2. Создайте API key.
3. Вставьте ключ в `GEMINI_API_KEY` в файле `.env`.
4. Проверьте актуальные лимиты и доступность модели в своём аккаунте.

Никогда не публикуйте `.env` и не отправляйте ключи в чаты.

## 3. Настроить Telegram

1. Создайте бота через `@BotFather` и скопируйте токен.
2. Добавьте своего бота администратором в публичный Telegram-канал с правом публикации сообщений.
3. Укажите токен в `TELEGRAM_BOT_TOKEN`.
4. В `TELEGRAM_CHANNEL` укажите `@username` канала.
5. Убедитесь, что канал уже связан с вашим каналом Дзена через синхробот Дзена.

## 4. Сначала тест без публикации

В `.env` оставьте `DRY_RUN=true`, затем выполните:

```bash
python -m app.main --once
```

Ожидаемый результат: Markdown-файл появится в `output/`, а журнал — в `logs/service.log`. Никакое сообщение в Telegram не отправляется.

## 5. Включить публикацию

После проверки текста установите `DRY_RUN=false` и выполните запуск вручную:

```bash
python -m app.main --once --force
```

Убедитесь, что сообщение появилось в Telegram, а затем проверьте его перенос в Дзен. `--force` повторно запускает обработку за текущую дату, поэтому используйте его осторожно: для реальной публикации это может создать дубликат.

## 6. Ежедневный запуск

```bash
python -m app.main
```

Окно терминала должно оставаться открытым, а компьютер — включённым и не переходить в сон. Для автозапуска после перезагрузки настройте Планировщик заданий Windows или systemd/cron на macOS/Linux.

## 7. Текущие известные ограничения

- Выбор темы пока использует сезонный список-кандидат и список ранее использованных тем.
- Проверка качества базовая и не является экспертной проверкой рецепта.
- Ошибка за день записывается в SQLite; повторный запуск за ту же дату требует `--force`.
- Изображения будут добавлены отдельным этапом после выбора действительно бесплатного локального или внешнего генератора.
